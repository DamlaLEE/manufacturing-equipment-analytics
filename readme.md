# 🏭 AI4I 제조 설비 상태 분석 대시보드

AI4I 2020 Predictive Maintenance Dataset을 활용하여 제조 설비의 운전 조건과 고장 현황을 탐색하는 Streamlit 기반 데이터 분석 대시보드입니다.

공기 온도, 공정 온도, 회전속도, 토크, 공구 마모 시간 등의 변수를 분석하고, 설비의 정상·고장 상태와 고장 유형별 특성을 시각적으로 확인할 수 있습니다.

참고) 해당 데이터는 합성 데이터이며, 출처는 [UCI Machine Learning Repository의 AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)입니다.

## 📌 프로젝트 소개

본 프로젝트는 제조 설비 데이터를 탐색적으로 분석하여 운전 조건과 고장 발생 간의 관계를 살펴보는 것을 목적으로 합니다.

사용자는 제품 유형(Type)을 선택하고, 분석 페이지별로 주요 지표와 시각화 결과를 확인할 수 있습니다.

## 🧭 버전 안내

| 파일 | 버전 | 주요 내용 |
|---|---|---|
| `app.py` | 기초 버전 | 전체 설비 현황, 온도 분석, 회전·부하 분석의 3개 페이지와 제품 유형 필터를 제공합니다. |
| `app_ver2.py` | 확장 버전 | 기초 버전의 분석에 고장 유형 분석, 공구 마모·온도 차이 구간별 고장률, 필터 데이터 CSV 다운로드를 추가합니다. |

두 앱은 모두 프로젝트 루트의 `data/ai4i2020.csv`를 사용합니다. `app_ver2.py`는 고장 유형 분석을 위해 `TWF`, `HDF`, `PWF`, `OSF`, `RNF` 컬럼도 필수 항목으로 확인합니다.

## ✨ 주요 기능 (`app_ver2.py` 기준)

### 1. 전체 설비 현황
- 전체 관측 건수 및 고장 관측 건수 확인
- 전체 고장률 및 평균 공구 마모 시간 확인
- 제품 유형(Type)별 데이터 규모 및 고장률 비교
- 정상·고장 데이터 구성 비율 확인
- 공구 마모 구간별 고장률 및 관측 건수 분석

### 2. 온도 분석
- 평균 공기 온도 및 공정 온도 분석
- 공기 온도와 공정 온도 분포를 정상·고장 상태별로 비교
- 정상·고장 그룹별 공정 온도와 공기 온도의 차이 비교
- 온도 차이 구간별 고장률 분석

### 3. 회전·부하 분석
- 평균 회전속도 및 토크 확인
- 추정 기계 동력 계산 및 분석
- 회전속도와 토크 간 관계 시각화
- 공구 마모 시간과 추정 기계 동력 간 관계 분석
- 정상·고장 그룹별 주요 운전 변수 요약

### 4. 고장 유형 분석
- 고장 유형별 플래그 건수 비교
- 고장 유형 플래그의 누적 비중 시각화
- 고장 유형별 집계 결과 확인

분석 대상 고장 유형은 다음과 같습니다.

| 코드 | 설명 |
|---|---|
| TWF | 공구 마모 관련 고장 |
| HDF | 방열·온도 관련 고장 |
| PWF | 동력 관련 고장 |
| OSF | 과부하 관련 고장 |
| RNF | 무작위 고장 유형 |

고장 유형 플래그는 한 관측치에서 중복될 수 있으므로, 유형별 플래그 합계가 전체 고장 관측 건수와 일치하지 않을 수 있습니다.

### 5. 데이터 필터링 및 다운로드
- 제품 유형(Type)별 데이터 필터링
- 현재 필터에 해당하는 데이터 미리 보기
- 필터링된 데이터의 CSV 파일 다운로드 (`app_ver2.py`)

## 📊 데이터 및 파생 변수

대시보드는 AI4I 2020 Predictive Maintenance Dataset의 설비 운전 변수와 고장 관련 컬럼을 사용합니다.

주요 입력 변수는 다음과 같습니다.

- `Type`: 제품 유형
- `Air temperature [K]`: 공기 온도
- `Process temperature [K]`: 공정 온도
- `Rotational speed [rpm]`: 회전속도
- `Torque [Nm]`: 토크
- `Tool wear [min]`: 공구 마모 시간
- `Machine failure`: 전체 고장 여부
- `TWF`, `HDF`, `PWF`, `OSF`, `RNF`: 고장 유형별 플래그

코드에서는 분석 편의를 위해 다음 파생 변수를 계산합니다.

- 공기 온도(°C)
- 공정 온도(°C)
- 공정 온도와 공기 온도의 차이
- 토크와 회전속도를 이용한 추정 기계 동력
- 정상·고장 상태 라벨
- 공구 마모 및 온도 차이의 탐색용 구간

추정 기계 동력은 다음 식으로 계산합니다.

\[
P = \tau \times \omega
\]

여기서 토크는 \(\tau\), 각속도는 \(\omega\)이며, 코드에서는 회전속도(rpm)를 초당 회전 각속도(rad/s)로 변환하여 계산합니다.

## ⚠️ 분석 시 유의사항

- AI4I 데이터셋은 실제 제조 현장에서 수집한 실측 데이터가 아닌 합성 데이터입니다.
- 데이터에서 관찰되는 관계만으로 고장의 원인이나 인과관계를 확정할 수 없습니다.
- 공구 마모 구간과 온도 차이 구간은 탐색을 위한 구분이며, 실제 현장의 공식 관리 기준이나 설비 교체 기준이 아닙니다.
- 계산된 기계 동력은 토크와 회전속도를 기반으로 한 추정값이며, 실제 전력 소비량과 동일하지 않습니다.
- 고장 유형별 플래그는 중복될 수 있으므로 유형별 건수와 누적 비중을 해석할 때 주의해야 합니다.
